# 💬 Chatbot Template | قالب چت‌بات

## فارسی

این یک چت‌بات ساده است که از مدل GPT-3.5 اوپن‌ای‌آی برای تولید پاسخ‌ها استفاده می‌کند. برای استفاده از این برنامه، باید یک کلید API اوپن‌ای‌آی ارائه دهید که می‌توانید آن را از [اینجا](https://platform.openai.com/account/api-keys) دریافت کنید. همچنین می‌توانید با دنبال کردن آموزش رسمی استریم‌لیت، ساخت این برنامه را مرحله‌به‌مرحله یاد بگیرید.

## English

This is a simple chatbot that uses OpenAI's GPT-3.5 model to generate responses. To use this app, you need to provide an OpenAI API key, which you can get [here](https://platform.openai.com/account/api-keys). You can also learn how to build this app step by step by following the official Streamlit tutorial.

[![Open in Streamlit](https://static.streamlit.io/badges/streamlit_badge_black_white.svg)](https://chatbotrg.streamlit.app/)

### Run on your own machine | اجرای برنامه روی سیستم شخصی

1. Install requirements | نصب پیش‌نیازها

   ```bash
   pip install -r requirements.txt
   ```

2. Run the app | اجرای برنامه

   ```bash
   streamlit run streamlit_app.py
   ```
